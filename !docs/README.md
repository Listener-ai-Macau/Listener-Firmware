# Docs

This directory keeps human-facing documents for the current product repository.

- `ai_development_workflow.md`: repo-level AI planning, step gating, and documentation workflow.
- `development_setup.md`: new machine bootstrap, build/flash workflow, and serial log usage.
- `plans/`: plan-first task and bug-fix documents with step acceptance checkpoints.
- `features/`: concise completion summaries for important implemented features or fixes.
- `product_solutions.md`: current product scope and feature boundary notes.
