# Listener 语音键盘用户手册

适用硬件：Voice Keyboard V1.0 ES8311 版本。

## 设备概览

Listener 语音键盘是一个 BLE 桌面语音输入设备。当前 V1.0 ES8311 硬件使用 EC11 旋钮按压作为语音键，KEY1-KEY4 作为 WASD 快捷键。

## 包装内含

- Listener 语音键盘设备。
- USB-C 充电线。
- 快速开始卡片。

## 按键布局

```text
+-----------------------------------+
| [KEY1] [KEY2] [KEY3] [KEY4]       |
|   D      W      A      S          |
|                                   |
|          [ EC11 旋钮 ]            |
|     按下=录音  旋转=音量          |
+-----------------------------------+
```

| 控件 | 功能 |
|---|---|
| EC11 旋钮按压 | 开始或停止语音录音 |
| EC11 顺时针旋转 | 电脑音量加 |
| EC11 逆时针旋转 | 电脑音量减 |
| KEY1 | D |
| KEY2 | W |
| KEY3 | A |
| KEY4 | S |

KEY1-KEY4 不触发语音录音。不要把 KEY1 当作语音键。

## 首次使用

1. 用 USB-C 给设备充电；首次使用建议充 1-2 小时。
2. 安装 Listener Type。内部测试下载入口见 `Listener-Type/docs/quickstart/voice-keyboard-download.md`。
3. 打开 Listener Type，点击「开始配对」。
4. 在 Windows 蓝牙窗口选择 `listener`。
5. 软件显示已连接后，按 EC11 旋钮开始第一次录音。

## 日常使用

| 场景 | 操作 |
|---|---|
| 开始录音 | 按一下 EC11 旋钮 |
| 停止录音 | 再按一下 EC11 旋钮 |
| 取消录音 | 按电脑键盘 `Esc` |
| 调节音量 | 旋转 EC11 旋钮 |
| 方向快捷键 | 使用 KEY1-KEY4 |

## 恢复和重新配对

当前内部测试版本提供桌面端/Windows 侧恢复路径：

1. 打开 Listener Type。
2. 设置 -> 关于 -> 忘记已配对设备。
3. 如果软件无法打开，进入 Windows 设置 -> 蓝牙和设备，删除 `listener`。
4. 重新打开 Listener Type，点击「开始配对」。

当前手册不承诺设备端长按硬件恢复出厂。若后续固件实现硬件恢复，应在对应版本更新本手册和快速开始卡片。

## 故障排除

| 问题 | 处理 |
|---|---|
| Windows 搜索不到设备 | 确认设备有电、蓝牙已打开，删除旧配对后重试 |
| 配对后无法录音 | 确认按下的是 EC11 旋钮 |
| 录音有反应但没有文字 | 检查 Listener Type 的 ASR/API Key 和网络，或使用 Demo 模式 |
| 旋钮无音量变化 | 检查电脑是否允许蓝牙 HID 媒体键 |
| 问题持续 | 在 Listener Type 设置 -> 关于 -> 导出诊断包 |

诊断包不包含录音、转写文本或 API Key。

## 安全与年龄提示

- 建议 13 岁以上使用。
- 内含小零件，不适合 3 岁以下儿童。
- 本产品是语音输入和轻量 AI 创作外设，不是玩具、医疗设备、心理治疗工具或儿童教育产品。

## 技术规格

| 项目 | 参数 |
|---|---|
| 主控 | ESP32-S3 |
| 蓝牙 | BLE 5.0 |
| 音频 | ES8311 Codec + 模拟麦克风 |
| 语音键 | EC11 旋钮按压 |
| 快捷键 | KEY1-KEY4 / WASD |
| 充电 | USB-C 5V |
