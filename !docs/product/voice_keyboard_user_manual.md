# Listener 语音键盘用户手册

适用硬件：Voice Keyboard V1.0 SPH0645 数字麦版本。

## 设备概览

Listener 语音键盘是一个 BLE 桌面语音输入设备。当前 N4 固件使用 EC11 旋钮按压作为语音录音键，KEY1-KEY4 作为自定义动作键；未配置桌面动作时，KEY1-KEY4 通过 F13-F16 提供安全 fallback。当前 N4 深睡唤醒使用 KEY4/GPIO21。

## 包装内含

- Listener 语音键盘设备。
- USB-C 充电线。
- 快速开始卡片。

## 按键布局

```text
+-----------------------------------+
| [KEY1] [KEY2] [KEY3] [KEY4]       |
|  F13    F14    F15    F16         |
|                                   |
|          [ EC11 旋钮 ]            |
|        单击=录音 双击=重新配对    |
+-----------------------------------+
```

| 控件 | 功能 |
|---|---|
| EC11 旋钮单击 | 开始或停止语音录音 |
| EC11 旋钮双击 | 清除设备端蓝牙配对/session 状态，并重新进入可配对状态 |
| EC11 旋钮长按 | 预留给硬件电源控制，不触发录音 |
| EC11 旋转 | 默认调节电脑音量，可由 Listener Type 设置为屏幕亮度或禁用 |
| KEY1 | 自定义动作键，fallback 为 F13 |
| KEY2 | 自定义动作键，fallback 为 F14 |
| KEY3 | 自定义动作键，fallback 为 F15 |
| KEY4 | 自定义动作键，fallback 为 F16；当前 N4 深睡唤醒键 |

KEY1-KEY4 不触发语音录音。语音录音键是 EC11 旋钮的按压动作。

## 首次使用

1. 用 USB-C 给设备充电；首次使用建议充 1-2 小时。
2. 安装 Listener Type。内部测试下载入口见 `Listener-Type/docs/quickstart/voice-keyboard-download.md`。
3. 打开 Listener Type，点击「开始配对」。
4. 在 Windows 蓝牙窗口选择 `listener`。
5. 软件显示已连接后，单击 EC11 旋钮开始第一次录音。

## 日常使用

| 场景 | 操作 |
|---|---|
| 开始录音 | 单击 EC11 旋钮 |
| 停止录音 | 再单击 EC11 旋钮 |
| 取消录音 | 按电脑键盘 `Esc` |
| 自定义动作 | 使用 KEY1-KEY4，在 Listener Type 中映射动作 |
| 深睡唤醒 | 当前 N4 按 KEY4/GPIO21 |

## 恢复和重新配对

当前内部测试版本提供设备端和桌面端两条恢复路径，都不需要打开 ESP-IDF 或读取串口日志。

### 设备端恢复

1. 确认设备有电。
2. 双击 EC11 旋钮。
3. 设备会清除已保存的蓝牙配对和当前录音 session 状态，并重新进入可发现配对状态。
4. 在 Windows 蓝牙设置里删除旧的 `listener` 设备。
5. 回到 Listener Type，点击「开始配对」。

内部调试或桌面端恢复入口也可以通过 USB Serial JTAG 发送 `~VREC:RECOVERY`、`~VREC:RESET` 或 `~VREC:FORGET`，效果相同：清除设备端 pairing/session 状态并重新等待配对。普通用户不需要手动输入这些命令。

### 桌面端/Windows 侧恢复

1. 打开 Listener Type。
2. 设置 -> 关于 -> 忘记已配对设备。
3. 如果软件无法打开，进入 Windows 设置 -> 蓝牙和设备，删除 `listener`。
4. 重新打开 Listener Type，点击「开始配对」。

恢复完成后，不需要判断串口日志。用户只需要看到 Listener Type 回到配对流程，或 Windows 蓝牙列表重新能搜索到 `listener`。

## 设备状态语言

固件日志使用统一的 `device_status state=<状态>` 格式，桌面端或诊断包可以映射成用户能理解的提示。

| 固件状态 | 用户提示 | 含义 |
|---|---|---|
| `ready` | 已准备好 | 设备已启动，或录音/恢复流程结束，可以重新配对或开始录音 |
| `recording` | 正在录音 | 语音键已触发，设备正在采集语音 |
| `transferring` | 正在传输 | 录音已停止，设备正在把音频 session 传给电脑 |
| `error` | 需要处理 | 录音、传输或恢复命令被拒绝；按软件提示重试或执行恢复 |
| `recovery` | 正在恢复 | 设备正在取消当前 session、清除配对并回到首次配对状态 |

## 故障排除

| 问题 | 处理 |
|---|---|
| Windows 搜索不到设备 | 确认设备有电、蓝牙已打开，删除旧配对后重试 |
| 配对后无法录音 | 确认按下的是 EC11 旋钮，不是 KEY1-KEY4 |
| 录音有反应但没有文字 | 检查 Listener Type 的 ASR/API Key 和网络，或使用 Demo 模式 |
| KEY1-KEY4 没有触发预期动作 | 在 Listener Type 设置 -> 快捷键里检查设备自定义键映射 |
| 深睡后按 EC11 没反应 | 当前 N4 使用 KEY4/GPIO21 唤醒；后续硬件再切到 RTC 唤醒旋钮键 |
| 旋钮无音量变化 | 在 Listener Type 设置里确认旋转动作未设为禁用；如刚更新固件，请在 Windows 蓝牙设置里删除并重新配对设备 |
| 问题持续 | 在 Listener Type 设置 -> 关于 -> 导出诊断包 |

诊断包不包含录音、转写文本或 API Key。

## 安全与年龄提示

- 建议 13 岁以上使用。
- 内含小零件，不适合 3 岁以下儿童。
- 本产品是语音输入和轻量 AI 创作外设，不是玩具、医疗设备、心理治疗工具或儿童教育产品。

## 技术规格

| 项目 | 参数 |
|---|---|
| 主控 | ESP32-S3 |
| 蓝牙 | BLE 5.0 |
| 音频 | SPH0645 I2S 数字麦克风 |
| 语音键 | EC11 旋钮按压 |
| 自定义键 | KEY1-KEY4 / F13-F16 |
| 当前 N4 深睡唤醒 | KEY4/GPIO21 |
| 充电 | USB-C 5V |
