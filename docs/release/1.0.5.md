# Listener Firmware 1.0.5

这是你买回去那台键盘上跑的软件。按下，说话，灯告诉你进行到哪。字由 [Listener Type 1.0.5](https://github.com/Listener-ai-Macau/Listener-Type) 写回光标。

装软件、看完整功能，以 Type 为准：

- [1.0.5 发布说明](https://github.com/Listener-ai-Macau/Listener-Type/blob/master/docs/release/1.0.5.md)
- [产品功能](../product/features.md)

## 手上怎么用

- 旋钮单击：开始或停止
- 旋钮双击：重新配对，Windows 里再选 `listener`
- 灯：电源、蓝牙、正在录、正在处理
- 唤醒：说「开始录音」；轻轻说，开头也留得住
- 升级：在 Type 里做，配对还在

没有 Type，这台键盘只是一块会亮灯的设备。字不会出现在光标里。

相对 1.0.4：灯和现在这台键盘对得上；轻声唤醒词不再被切掉开头。关机后电量有时会显示不准，还没进这一包。

## 装哪个文件

和 Type 1.0.5 一起用的日常升级包：

```powershell
Get-FileHash -Algorithm SHA256 .\ListenerFirmware_1.0.5_ota.zip
```

在 Type 里升级。不要只刷键盘、却继续用旧的 Type。不要把 `build/` 里的 zip 当成这一包。GitHub 上的同名文件以该页哈希为准，对不上就不要混。

# Listener Firmware 1.0.5

This is the software on the keyboard you buy. Press, speak, watch the lights. [Listener Type 1.0.5](https://github.com/Listener-ai-Macau/Listener-Type) puts the words at the cursor.

Install the app and read the full product notes in Type: [1.0.5](https://github.com/Listener-ai-Macau/Listener-Type/blob/master/docs/release/1.0.5.md).

Click the knob to start or stop. Double-click to re-pair. Lights for power, Bluetooth, recording, and processing. Wake phrase “开始录音” — even said quietly, the beginning stays. Upgrade from Type; pairing remains.

Without Type, the keyboard is a BLE device with lights. Text will not appear at the cursor.

Versus 1.0.4: the lights match this keyboard; a quiet wake phrase is no longer cut at the start. Battery reading after power-off can still be wrong; that fix is not in this package.

Daily OTA with Type 1.0.5: `ListenerFirmware_1.0.5_ota.zip`, SHA-256 `D993765AC07838F798B71863F87A69A59DAC9EE47CBBCE3315266FBBB631BADC`. Upgrade inside Type. Same filename is not the same build.
