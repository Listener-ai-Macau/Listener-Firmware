# 键盘灯语与状态

**简体中文** · [英文](status_led.md)

六位状态区依次标为 PWR、BLE、REC、AI、OK、WARN。灯名与颜色、节奏一起读；它们分别表示供电、连接、录音、处理、完成和需要关注的问题。

| 灯名 | 含义与显示 |
| --- | --- |
| PWR（电源） | 电池用绿、琥珀、红表示电量；极低电量红双闪。充电时白色呼吸，确认充满后白常亮。 |
| BLE（连接） | 蓝色脉冲表示配对或重连；暗蓝双闪表示已有蓝牙连接、软件尚未就绪；蓝常亮表示软件就绪。未连接、空闲或全部关闭状态可熄灭。 |
| REC（录音） | 实际采音时，金色随声音变化。启用语音唤醒时，熄灭不表示麦克风完全关闭。 |
| AI（处理） | 紫色节拍表示停止后的传输或电脑文字处理。 |
| OK（完成） | 主机报告完成后，绿色短亮约两秒；无线更新时显示青绿色进度。 |
| WARN（提醒） | 琥珀或红色表示需要检查软件中的错误信息。 |

## 亮度和空闲

设备页可分别设置状态区、按键、旋钮与板边亮度。亮度不改变麦克风音量、声纹判断或自动结束条件。

电池默认空闲一分钟进入低功耗，十分钟关机；插电默认三分钟低功耗，不自动关机。低功耗保留电源提示，其余灯和装饰区域可熄灭。按键或旋钮唤醒低功耗；真正关机后用旋钮开机。修改计时和亮度后，确认设备连接与写入成功。

## 连接和恢复

Windows 显示已配对，不等于软件已经就绪。先确认 Type 的连接检查与录音来源。双击旋钮重置配对；必要时删除 Windows 旧 `listener` 记录再重配。重配会给出蓝色确认提示，普通无线更新保留已有配对与设置。

实物丝印和对应批次固件是核对灯位与默认值的依据。[返回中文键盘首页](../../README.zh-CN.md)。
