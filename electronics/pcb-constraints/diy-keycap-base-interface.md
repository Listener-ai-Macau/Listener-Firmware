## 有线功能样约束

有线功能样用于快速验证 `4` 键、`1` 旋钮、麦克风和 Type-C 位置，不要求锂电池工作闭环。

- PCB 仍采用同一 `110 x 38 mm` 外形和同一输入件坐标，避免外观 CAD 返工。
- Type-C 可先承担供电、调试和数据；如使用开发板/飞线小板，仍需把外壳开口和连接器中心锁在 `(60, 0)`。
- 麦克风必须放在最终声孔附近，不建议为了走线方便临时移到 PCB 中央。
- 有线样可不装电池，但电池包络必须保持空置，不得被调试排针永久占用。

## 无线锂电版新增约束

- 锂电池充电路径默认 `5 V Type-C -> 充电 IC -> 单节 LiPo`，电池保护板和 NTC 方案后续由电子设计冻结。
- 充电 IC、LDO/DCDC、采样分压等热源不要贴近电池中心，优先放在 Type-C 附近并给铜皮散热。
- 天线净空区 `X 88-116`, `Y 6-18` 不铺铜，不走高速/电源大电流线，不放金属外壳固定件。
- 电池线束从电池右侧或上侧出线，避开 encoder 固定脚和 Type-C 插拔区。
- 充电状态 LED 如需要，建议靠 Type-C 左右两侧布置，不进入麦克风声孔和天线净空。

## 信号与噪声分区

| 分区 | 建议 |
|---|---|
| 输入扫描 | 4 个按键和编码器走线靠顶面，避开天线净空边缘 |
| 麦克风 | 远离充电开关节点和编码器 A/B 线，必要时加地护线 |
| 电源/充电 | 集中在 Type-C 周边，减少穿过麦克风区域 |
| BLE 射频 | 天线馈线短直，参考地连续到天线匹配网络前，净空处禁铜 |
| 电池 | 线束固定点和防拉扯结构需由 PCB 与底壳共同承担 |

## CAD/PCB 冻结建议

第一轮外观 CAD 集成前建议冻结以下项目：

1. 底座外轮廓 `120 x 50 mm`。
2. 4 个按键中心：`(18,30)`, `(42,30)`, `(66,30)`, `(90,30)`。
3. 旋钮中心：`(108,30)`。
4. Type-C 开口中心：`(60,0)`。
5. 麦克风声孔中心：`(18,12)`。
6. BLE 天线净空：`X 88-116`, `Y 6-18`。
7. 电池最大包络：`46 x 18 x 5 mm`，中心 `(52,14)`。

后续允许在不影响以上冻结点的前提下微调 PCB 边缘、安装孔、元件丝印和测试点。
