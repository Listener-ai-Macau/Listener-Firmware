# DIY Cute Keycap Base Hardware Envelope v0.1

状态：内部布局初稿，用于外观 CAD 和结构草模集成  
日期：2026-05-20  
坐标基准：底座俯视图左下角为 `(0, 0)`，单位 `mm`，`X` 向右，`Y` 向上

## 设计目标

本包络定义 `120 x 50 mm` 小型底座内的首版硬件占位：`4` 个可换可爱键帽 socket、`1` 个可换旋钮帽 socket、主 PCB、锂电池、Type-C 充电口、麦克风、BLE 天线和基础安全禁入区。它服务于第一版工业设计和结构试水，不作为最终量产堆叠。

对应坐标图：[diy-keycap-base-coordinate-map.svg](./diy-keycap-base-coordinate-map.svg)

## 关键结构约束

- 4 个键帽 socket 采用统一 `24 mm` 中心距，先保证可爱主题帽有外扩空间；后续若键帽库需要更胖造型，优先压缩旋钮帽外径而不是压缩电池安全区。
- 旋钮帽中心放在 `(108, 30)`，右边缘只留 `12 mm`，因此旋钮帽外径首版建议 `22-24 mm`，并用局部切边或低圆角外形避免超出底座视觉边界。
- 麦克风声孔不放在顶面中心，避免被手掌和键帽遮挡；声学腔体先按 `10 x 6 x 2 mm` 预留，声孔阵列由 ID 再定。
- Type-C 口朝底边，机械开口需独立于 PCB 外形校核；外壳内侧建议预留 `1.0 mm` 装配浮动和插拔倒角。
- BLE 天线区放在右下角，保持远离电池、Type-C 金属壳和编码器金属壳；外壳此处避免金属装饰、电镀、磁吸件。
- 电池位于下半区偏左，目标容量先按 `300-500 mAh` 软包评估；电池厚度、保护板和线束弯折空间必须共同计入。

## 安全与禁入区

| 区域 | 约束 |
|---|---|
| 电池上方 | 不放尖锐柱脚、螺丝尾、未倒角筋位；电池上方至少 `0.5 mm` 软隔离 |
| Type-C 周边 | 连接器壳体两侧 `2 mm` 内不放高筋，避免插头干涉 |
| 天线净空 | 净空区上下表面不得有铜、屏蔽罩、电池、磁铁或金属贴片 |
| 按键运动区 | 每个 socket 周围 `20 x 20 mm` 内避免固定筋穿过按压导向路径 |
| 旋钮受力区 | 编码器周围需要独立支撑柱或 PCB 加固，避免旋转/按压掰板 |

## 给外观 CAD 的交付口径

- 外观第一版可以把 `120 x 50 mm` 作为硬边界，把 SVG 中的 socket 中心作为可视元素中心。
- 顶面造型可以覆盖 PCB 和电池，但不得侵入按键、旋钮、Type-C、麦克风声孔和天线净空。
- 若主题键帽需要更强角色感，建议先改变键帽高度和轮廓，不移动 socket 中心。
- 该包络允许后续 PCB 微调 `+/-1 mm`，但 Type-C、天线、键帽中心和旋钮中心应在 CAD v0.6 前冻结。
