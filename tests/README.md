# Tests

这里先保留自动测试目录入口。

当前目录规则：

- `tests/*.wav`
  - 主机侧运行时产物
  - 临时生成，可按需清理，不提交
- `tests/*.log`
  - 主机侧串口 / 接收 / 回归日志产物
  - 临时生成，可按需清理，不提交
- `tests/artifacts/`
  - 放自动回归时生成的临时源音频或其它中间产物
  - 默认只长期保留少量人工验收证据，例如 `tests/artifacts/p11_single/` 和 `tests/artifacts/p11_rerun_20260515/`
  - 其它矩阵、声源、日志和 WAV 产物都可以重新生成

当前已经具备一个最小测试脚本入口：

- `tools/test.ps1`
  - 重新构建工程
  - 检查 `bin`、`bootloader.bin`、`partition-table.bin`

- `P12` 弱环境 / 距离 / 干扰实验
- `P13` 后端闭环联调
